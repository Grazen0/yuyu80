## Memory map

### Memory space

|    Range    | Description |
| :---------: | :---------: |
| `0000-7FFF` |     ROM     |
| `8000-FFFF` |     RAM     |

### I/O space

| Range | Description |
| :---: | :---------: |
| `00`  | PIO data A  |
| `01`  | PIO ctrl A  |
| `02`  | PIO data B  |
| `03`  | PIO ctrl B  |
| `40`  |  LCD data   |
| `41`  |  LCD ctrl   |
